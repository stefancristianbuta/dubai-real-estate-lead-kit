# Dubai Real Estate Lead Kit

Landing page for the Dubai Real Estate Lead Kit.

## Deploy

Static site. Entry point: index.html. No build step required.

Before launch, replace CHECKOUT_URL in index.html with the live checkout URL.

## Product

AED 99. Includes 50 WhatsApp scripts, 20 follow-up messages, 20 AI prompts, 30 content ideas, Lead CRM, ROI calculator and PDF guide.
